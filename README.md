# Accessible Alternative Text for Real Estate Listings – PoC

A proof-of-concept application for managing accessible alternative text for real estate listing images. The application displays properties for sale and provides an admin interface for managing listing and image data.

## Technologies

Next.js 16, React 19, TypeScript, Prisma, PostgreSQL, NextAuth, and Mantine.
